# Sources and notes

**Offer facts checked October 22, 2026.** Developer-infrastructure links were added October 24, 2026. These are official provider pages unless noted. Provider pages change without notice; a link working today is not proof that an offer still exists. Use these as the starting point for your own verification, not as permanent terms.

This guide distinguishes between:

- **Free tier:** an ongoing, limited allowance.
- **Trial credit:** a time-limited balance.
- **Program credit:** an application- or eligibility-based offer.
- **Open-source or local:** software you run yourself, with hardware and maintenance costs.

## Notes on method

We checked the official pages above in October 2026. Where a provider's page did not expose a stable limit—or where the limit depended on region, account history, model, or plan—the guide says so rather than inventing a number. Secondary sources were used only to find official pages or to note industry coverage; they are not the basis for eligibility claims.
